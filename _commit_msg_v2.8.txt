## 任务 1：补仓/减仓记账计算器（核心刚需）
替换原 syncGridPrice（静默覆盖基准价）为 openAdjustDialog（弹 Dialog）
- Dialog 字段：成交价（默认现价）、成交数量（正数加仓/负数减仓/0 忽略）
- 实时预览：原值展示 + 加权平均成本 + 新持仓 + 新基准价
- 核心算法（前端计算，confirm 后 PATCH 一次同步 3 个字段）：
    new_pos = old_pos + qty
    if 加仓: new_cost = (old_cost * old_pos + trade_price * qty) / new_pos
    if 减仓: new_cost = old_cost  （减仓不动成本）
    last_grid_price = trade_price
- 边界处理：原持仓 0 + 减仓 → 报错；减仓后 ≤ 0 → 报错；成交价 ≤ 0 → 报错
- 单元测试 7/7 通过（含 sh589130 实战：1.69+1.436 加仓 1000股 → 1.563）
